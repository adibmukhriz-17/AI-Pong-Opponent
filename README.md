# AI-Pong-Opponent
Python Pong game featuring rule-based and machine learning AI opponents, built with Pygame and scikit-learn to compare scripted vs learned gameplay behaviour.

This project is an interactive Pong game developed in Python that explores the difference between traditional rule-based AI and data-driven machine learning opponents.

The game includes a fully playable Pong environment with scorekeeping, difficulty settings, and two AI behaviours:

- Rule-Based AI: uses deterministic logic to track and respond to the ball.
- MLP AI (Machine Learning): uses a trained neural network model to imitate decision-making behaviour based on gameplay state features.

The project was designed as a small experimental AI environment to compare scripted logic versus learned behaviour in a real-time interactive game.

## Features
- Playable Pong game with keyboard controls
- Rule-based AI opponent
- Machine learning AI opponent using MLPClassifier
- Difficulty levels (Easy / Medium / Hard)
- Score tracking
- AI performance comparison metrics:
  - AI hit rate
  - rally length
  - final score
- Real-time game rendering with Pygame

## Tech Stack

- Pygame
- NumPy
- Pandas
- Scikit-learn
